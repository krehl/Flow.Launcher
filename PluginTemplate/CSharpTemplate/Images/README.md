# Plugin Icon

Add your plugin icon here as `icon.png`.

## Recommended Specifications

- **Size**: 256x256 pixels
- **Format**: PNG with transparency
- **Style**: Simple, clear, and recognizable
- **Color**: Should work well on both light and dark themes

## Design Tips

1. Use a simple, distinctive design
2. Avoid text in the icon (it won't be readable at small sizes)
3. Use high contrast colors
4. Test on both light and dark backgrounds
5. Keep it simple - the icon will often be displayed at 32x32 or smaller
